# Конструктор коммерческих предложений

Автономный браузерный прототип для подготовки персонализированных коммерческих предложений по телекоммуникационным услугам для юридических лиц.

## Возможности

- карточка клиента и его потребностей;
- выбор услуг и ручная корректировка цен и количества;
- расчёт скидки и НДС 16%;
- предварительный просмотр предложения;
- печать или сохранение предложения в PDF;
- локальное сохранение черновика в браузере.

## Запуск

Скачайте или клонируйте репозиторий и откройте файл `kztelecom-kp-constructor.html` в любом современном браузере.

## Важно

Цены, включённые в прототип, являются справочными. Перед отправкой клиенту необходимо подтвердить актуальный прейскурант, техническую возможность подключения, разовые платежи и индивидуальные условия.
